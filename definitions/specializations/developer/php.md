## Responsibilities [append]

Use the PHP version, extensions, framework conventions, and dependency constraints declared by the project. Inspect Composer configuration and lockfiles before choosing APIs or dependencies. Preserve the established approach to strict typing; do not introduce a project-wide policy in a local fix.

Keep input parsing and validation at relevant boundaries. Use parameterized database access and context-appropriate output encoding. Respect framework protection for authentication, authorization, CSRF, and orbes; do not bypass it with custom shortcuts.

Make nullability, value conversions, exceptions, and collection shapes clear where they affect correctness. Consider request lifecycle, transactions, repeated submissions, background jobs, and long-running worker state where applicable. Avoid exposing sensitive data through error responses or logs.

Follow the existing separation of request handling, application logic, and persistence. Do not assume a particular framework or ORM.
